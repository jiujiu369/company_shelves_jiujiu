# 千牛批量录入项目

本项目用于把一个商品文件夹中的图片、SKU、正式价格库存和属性，自动填写到千牛并放入仓库。

当前已有可运行的本机可视化工作台、命令行程序和中文启动菜单，包括开始前准备检查、资料校验、图片清单、SQLite记录、独立Playwright接口、填写与全量核对、单次提交恢复和Qwen辅助模块。

最新起点改为“以图发品”，JG图片来源已按用户要求切换为已确认本地目录。已实现清单筛选、上传接口与防重传记录，230项内部测试通过；已只读确认专用浏览器处于正确店铺的以图发品页面。图片实际上传、识别后选择类目以及详情/SKU上传绑定仍待接入和现场验证，不能当作完整自动上传已可用。编辑配置可选择图片来源和目录；改目录会取消旧上传确认。详见《启动与恢复说明.md》和《验证报告.md》。

**真实入仓尚未跑通，没有新商品编号。** 当前已真实创建唯一JG6-6，并用“更多批量”应用、读回100元、999库存、6平方毫米、单芯多股芯，总库存999。两标题60/60、30/30、基础属性、浙江省温州市、包邮、48小时及放入仓库也已读回。用户确认本次一件就是一包，已保留平台原单位并按配置核对；图片完整内容、SKU图片关联、可选包装数量实际空值、仓库与编辑页回查仍待完成，提交保持禁用。

## 启动

双击 `打开工作台.cmd`，打开可视化界面。工作台仅在本机运行，默认地址为 http://127.0.0.1:8766；端口被占用会选择其他端口。旧命令行菜单仍可双击 `启动.cmd` 使用。当前环境已经安装依赖，无需重新部署模型。

工作台首先展示“开始前准备”：商品必填与来源、本地图片检查、物流和放入仓库，以及登录正确店铺、整理素材版本、价格库存单位、停止同时编辑四项人工确认。准备按商品资料版本持久记录，资料或图片变更后重新确认；准备勾选不产生平台核对结果，也不能解除提交禁用。按钮实际运行原有脚本，显示步骤、待补资料、上次逐字段核对、现场截图、执行记录和商品编号，不模拟进度。

先选“1 资料校验”，再选“2 打开浏览器”和“3 登录检查”。截图中的专用浏览器已打开时会复用，不会重新创建登录窗口。程序退出后不会主动关闭它；浏览器异常关闭的原因目前没有确认。日常Chrome不能仅凭已经登录就被独立程序接管，首次使用专用目录需要手动登录。

最新指令：用户已手动修改详情顺序，程序停止自动排序并保留当前排列。该记录不放行图片内容或提交。用户已手工补入并替换详情09 v4，程序读回完整文件名、素材编号1401108857048358685及同一表单图片资产；这是素材编号，不是商品编号。9组详情的文件名和分段尺寸已对应，JPEG完整内容仍未接受。JG6-6素材大图已取得，但尚未关联SKU图片。仓库入口和全分页读取现已实际通过：3页、50个唯一商品编号，两次集合一致；这不是JG入仓成功。没有保存草稿或提交，不要改 `verified` 强行放行。

工作台支持自行选择本地商品JSON配置并导入副本；“商品资料”中可编辑字段、价格、库存、来源与待补原因，也可选择图片目录。“完整配置”可修改SKU组合、图片文件名和商品规则。保存保留旧版本并使受影响的平台核对失效，不能覆盖未知提交中的资料。未知值可以保存，不填正式价格库存默认值。详见启动说明。

导航现按`#overview/#checks/#events/#facts`区分内容；流程、任务操作和执行状态仅属于工作台，不再挡住手机上的其他页面。顶部新增“编辑当前商品配置”。按钮发起任务后滚动到对应执行反馈，历史任务明确显示“当前未运行”和“上次耗时”。打开网页或切换导航不启动任务。

“商品资料”内的Qwen助手可选择配置中的图片进行资料提取，也可按已确认标题事实生成建议。沿用原服务和模型，不重新部署；结果按资料版本保存，不自动改配置、不操作千牛。来源编号绑定输入事实，标题计数和品牌词由脚本校验，不合格建议明确标记，不堆词补齐。

详细操作见 [启动与恢复说明](启动与恢复说明.md)，状态和证据见 [验证报告](验证报告.md)。

## 配置与记录

- `products/jg-test.json`：仅JG6-6测试，100元/包、999包、总999，不是正式商品默认值。
- `products/product.example.json`：正式商品配置示例；未知值用null，保留来源、原因和确认状态。
- `config.json`：专用浏览器、原Ollama服务和持久记录位置。
- `profiles/qianniu.json`：平台控件绑定，当前缺失的绑定会明确暂停，不会假造读取结果。
- `运行记录/state.sqlite`：资料版本、步骤、逐字段核对、不可变完整观测、提交意图和人工处理记录。
- `运行记录/<task_id>/`：资料校验、素材清单、现场截图与回读、任务报告。

关机或中断后选择“7 恢复”，程序重新读取当前平台。若已写入提交意图，则只能先查仓库和编辑页，不会再次点击提交。查不到商品不等于未提交，本地日志也不证明平台已保存。

请先阅读[千牛批量上架执行方案](千牛批量上架执行方案.md)。

模型服务沿用`http://192.168.1.9:11434`与`qwen3.5:4b-q4_K_M`，不重新部署。

正式商品必须提供真实的价格、库存、销售单位及来源；可选包装数未知时保持空白，不能拿库存代替每包数量。全部商品标题执行60/60、导购标题30/30且不含品牌词的既定规则。Qwen只提供有来源、未确认的提取与建议，不决定提交。
